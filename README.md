# Calculadora de IMC

Calculadora de IMC (índice de massa corporal) feita em React Native com Expo. Projeto de estudo.

## Tecnologias

- React Native com Expo
- React Native Web

## Como executar

```bash
npm install
npx expo start
```

Depois, abra o app no celular com o Expo Go (leia o QR code) ou em um emulador.
